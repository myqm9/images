# taste-skill (project install)

This project installs [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill).

Primary skill files:

- `skills/taste-skill/SKILL.md` - main anti-slop frontend skill
- `skills/redesign-skill/SKILL.md` - upgrade existing sites without full rewrite
- `skills/minimalist-skill/SKILL.md` - restrained layouts
- `skills/brutalist-skill/SKILL.md` - high-contrast editorial

When redesigning UI in this repo, read `skills/redesign-skill/SKILL.md` first for preserve-mode audits, then apply `skills/taste-skill/SKILL.md` pre-flight checks.
