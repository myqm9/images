采用 docker-compose 容器编排方式部署。本页为官方镜像 MySQL 5.7.44，认证插件为 `mysql_native_password`。MySQL 8 请用标题旁的版本切换。

:::caution
`MYSQL_ROOT_PASSWORD` 与 healthcheck 中的 root 密码必须一致，**生产环境改成自己的密钥**，不要使用文档中的占位符。
:::

## 发布信息

- AMD64 镜像：`{{ image.amd64.reference }}`
- ARM64 镜像：`{{ image.arm64.reference }}`

当前为官方镜像，AMD64 / ARM64 使用同一 tag。

## 前提条件

- 已完成 [Docker 与 Compose](/prerequisites/docker/) 安装，并已创建 `tsingyun` 自定义网络。

## 创建工作目录

```bash
mkdir -p /home/application/Database/mysql/{data,etc,init}
```

## 编辑 my.cnf

编辑 `/home/application/Database/mysql/etc/my.cnf`。

不是所有参数都适合照搬：`innodb_buffer_pool_size` 建议设为系统内存的 50% 或更低，专用库可酌情提高，不要直接使用示例中的 `8G`。5.7 的 `sql_mode` 含 `NO_AUTO_CREATE_USER`，binlog 过期使用 `expire_logs_days`。

```ini
[mysqld]
# MySQL 服务运行的用户
user=mysql

# 监听端口
port=3306

# 最大连接数
max_connections=1000

# 默认存储引擎
default-storage-engine=INNODB

# 服务器默认字符集与校对规则
character-set-server=utf8mb4
collation_server=utf8mb4_general_ci

# 禁用域名解析，只允许 IP 登录
skip-name-resolve=1

# 表名不区分大小写
lower_case_table_names=1

# 日志时间戳使用系统时间
log_timestamps=SYSTEM

# 默认时区
default-time-zone=+8:00

# 慢查询
long_query_time=3
slow_query_log=ON
slow_query_log_file=/var/lib/mysql/slow_query.log
log_queries_not_using_indexes=0
log_slow_admin_statements=1
log_slow_slave_statements=1
log_throttle_queries_not_using_indexes=10

# 通用日志通常不开启
# general_log=1
# general_log_file=/var/lib/mysql/mysql_general.log

# 错误日志
log-error=/var/lib/mysql/mysqld.log

# 缓冲池与缓存（按主机内存调整 buffer pool）
innodb_buffer_pool_size=8G
innodb_log_buffer_size=4M
table_open_cache=16384
table_definition_cache=16384

# 二进制日志与复制（server_id 需唯一）
server_id=19
log-bin=mysql-bin
max_binlog_size=100M
binlog_format=row
log_slave_updates
expire_logs_days=7

binlog-ignore-db=mysql
binlog-ignore-db=information_schema
binlog-ignore-db=sys
binlog-ignore-db=performance_schema

replicate-ignore-db=mysql
replicate-ignore-db=information_schema
replicate-ignore-db=sys
replicate-ignore-db=performance_schema

# 禁用 SSL
skip_ssl

socket=/var/run/mysqld/mysqld.sock
sql_mode=STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_AUTO_CREATE_USER,NO_ENGINE_SUBSTITUTION
max_allowed_packet=512M

[mysql]
socket=/var/run/mysqld/mysqld.sock
default-character-set=utf8mb4

[client]
default-character-set=utf8mb4
```

## 上传初始化 SQL（可选）

首次启动且数据目录为空时，才会执行 `init` 目录中的脚本。

园区项目可从 [mysql docker-compose 模板目录](https://file.tsingyun.link/docker/Database/mysql/docker-compose/) 获取脚本；**企业项目请忽略**。

```bash
cd /home/application/Database/mysql/init

# 授权 JDBC 用户，按现场修改授权地址
# create-user.sql

# Apollo 初始化，按现场修改变量
# tsingyun-apollo-2.1.0.sql

# 基线库初始化（必要时）
# tsingyun-baseline-init.sql
```

放入前按现场修改授权地址与变量占位符。

## 编写 docker-compose.yml

编辑 `/home/application/Database/mysql/docker-compose.yml`。必须配置 root 密码，且 **healthcheck 使用同一密码**。

```yaml
services:
  mysql:
    restart: always
    image: {{ image.amd64.reference }}
    container_name: mysql
    networks:
      - tsingyun
    volumes:
      - /home/application/Database/mysql/data:/var/lib/mysql
      - /home/application/Database/mysql/etc:/etc/mysql/conf.d
      - /home/application/Database/mysql/init:/docker-entrypoint-initdb.d
      - /etc/localtime:/etc/localtime:ro
    environment:
      MYSQL_ROOT_PASSWORD: "YOUR_MYSQL_ROOT_PASSWORD"
      TZ: "Asia/Shanghai"
    ports:
      - 3306:3306
    command: --explicit_defaults_for_timestamp=true
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-u", "root", "-pYOUR_MYSQL_ROOT_PASSWORD"]
      interval: 30s
      timeout: 10s
      retries: 3

networks:
  tsingyun:
    external: true
```

## 设置目录权限

```bash
chmod -R 777 /home/application/Database/mysql/data
chmod 644 /home/application/Database/mysql/etc/my.cnf
```

:::caution
- 数据目录未设可写权限时，入口脚本执行 init SQL 会报 `Permission denied`。
- `my.cnf` 若权限过宽（例如 world-writable），会被忽略并出现 `World-writable config file ... is ignored` 警告。
:::

## 启动容器

```bash
cd /home/application/Database/mysql
docker-compose up -d
docker-compose ps
```

预期服务名为 `mysql`，端口映射 `3306`。

```bash
docker exec mysql mysqladmin ping -u root -p'YOUR_MYSQL_ROOT_PASSWORD'
```

数据目录必须纳入备份。
