采用 docker-compose 容器编排方式部署。本页为 InfluxDB 3.9.0，使用 file object store，默认监听 `8181`，不带内置 Web UI。可选附带 `influxdb-explorer` 与 Nginx 代理（`3100`）。InfluxDB 2（端口 `8086`、带 UI）请用标题旁的版本切换。

:::caution
初始化用户名、密码、组织和 Token 写在 compose 的环境变量中，**生产环境必须改成自己的密钥**，不要使用文档中的占位符。
:::

## 发布信息

- AMD64 镜像：`{{ image.amd64.reference }}`
- ARM64 镜像：`{{ image.arm64.reference }}`

`influxdb-explorer`（Influxdb3-ui）镜像：

- AMD64：`harbor.tsingyun.net/tsingyun-middleware/influxdb:influxdb3-ui-1.6.3`
- ARM64：`harbor.tsingyun.net/tsingyun-middleware/influxdb:influxdb3-ui-1.6.3-arm64`

`influxdb-proxy` 使用 Nginx 镜像：

- AMD64：`harbor.tsingyun.net/tsingyun-middleware/nginx:1.28.3`
- ARM64：`harbor.tsingyun.net/tsingyun-middleware/nginx:1.28.3-arm64`

## 前提条件

- 已完成 [Docker 与 Compose](/prerequisites/docker/) 安装，并已创建 `tsingyun` 自定义网络。
- ARM64 主机请将下方 compose 中的 `image` 换成发布信息中的 ARM64 镜像。

## 创建工作目录

```bash
mkdir -p /home/application/Database/influxdb/data
mkdir -p /home/application/Database/influxdb/plugins
chmod -R 777 /home/application/Database/influxdb/data
chmod -R 777 /home/application/Database/influxdb/plugins
```

## 编写 docker-compose.yml

编辑 `/home/application/Database/influxdb/docker-compose.yml`。将 `YOUR_EXPLORER_PASSWORD` 换成 Explorer 代理的 Basic Auth 密码。

```yaml
services:
  influxdb:
    image: {{ image.amd64.reference }}
    container_name: influxdb
    restart: always
    ports:
      - "8181:8181"
    command:
      - influxdb3
      - serve
      - --node-id=node0
      - --object-store=file
      - --data-dir=/var/lib/influxdb3/data
      - --plugin-dir=/var/lib/influxdb3/plugins
    volumes:
      - /home/application/Database/influxdb/data:/var/lib/influxdb3/data
      - /home/application/Database/influxdb/plugins:/var/lib/influxdb3/plugins
      - /etc/localtime:/etc/localtime:ro
    healthcheck:
      test: ["CMD", "nc", "-z", "127.0.0.1", "8181"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 30s
    networks:
      - tsingyun

  influxdb-explorer:
    image: harbor.tsingyun.net/tsingyun-middleware/influxdb:influxdb3-ui-1.6.3
    container_name: influxdb-explorer
    command: --mode=admin
    volumes:
      - /etc/localtime:/etc/localtime:ro
    healthcheck:
      test: ["CMD", "nc", "-z", "127.0.0.1", "80"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 30s
    networks:
      - tsingyun

  influxdb-proxy:
    image: harbor.tsingyun.net/tsingyun-middleware/nginx:1.28.3
    container_name: influxdb-proxy
    depends_on:
      - influxdb-explorer
    entrypoint:
      - sh
      - -euc
      - |
        # 生成 htpasswd（用户名 admin，密码换成自己的）
        printf "admin:$$(openssl passwd -apr1 YOUR_EXPLORER_PASSWORD)\n" > /etc/nginx/.htpasswd

        cat <<EOF > /etc/nginx/nginx.conf
        user  nginx;
        worker_processes  5;

        events {
          worker_connections   1000;
        }

        http {
          resolver 127.0.0.11;

          server {
            listen             3100;

            # Basic Auth
            auth_basic "InfluxDB Explorer - Restricted Access";
            auth_basic_user_file /etc/nginx/.htpasswd;

            location / {
                    proxy_pass http://influxdb-explorer/;
            }
          }
        }
        EOF
        /docker-entrypoint.sh nginx -g "daemon off;"
    ports:
      - "3100:3100"
    healthcheck:
      test: ["CMD", "service", "nginx", "status"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - tsingyun

networks:
  tsingyun:
    external: true
```

不需要 Explorer 时，可删除 `influxdb-explorer` 与 `influxdb-proxy` 服务。

## 启动容器

```bash
cd /home/application/Database/influxdb
docker-compose up -d
docker-compose ps
```

## 创建管理员 Token

进入容器生成管理员 Token，并保存在密钥系统，不要写入文档：

```bash
docker exec -it influxdb bash
influxdb3 create token --admin
```

## 创建数据库

```bash
docker exec -it influxdb bash

export INFLUXDB3_AUTH_TOKEN=YOUR_INFLUXDB_ADMIN_TOKEN
influxdb3 create database tsingyun

# 查看数据库
influxdb3 show databases
```

## 访问 Explorer

通过 `influxdb-proxy` 转发访问 Explorer：浏览器打开 `http://YOUR_SERVER_IP:3100`，使用 Basic Auth 用户名 `admin` 与 compose 中配置的 `YOUR_EXPLORER_PASSWORD` 登录。

数据目录必须纳入备份。
