采用 docker-compose 容器编排方式部署。本页为 InfluxDB 2.9.1，默认监听 `8086`，自带 Web UI。InfluxDB 3 请用标题旁的版本切换。

:::caution
初始化用户名、密码、组织和 Token 写在 compose 的环境变量中，**生产环境必须改成自己的密钥**，不要使用文档中的占位符。
:::

## 发布信息

- AMD64 镜像：`{{ image.amd64.reference }}`
- ARM64 镜像：`{{ image.arm64.reference }}`

## 前提条件

- 已完成 [Docker 与 Compose](/prerequisites/docker/) 安装，并已创建 `tsingyun` 自定义网络。
- ARM64 主机请将下方 compose 中的 `image` 换成发布信息中的 ARM64 镜像。

## 创建工作目录

```bash
mkdir -p /home/application/Database/influxdb/data
chmod -R 777 /home/application/Database/influxdb/data
```

## 编写 docker-compose.yml

编辑 `/home/application/Database/influxdb/docker-compose.yml`。指定自己的密码与 Token，并关闭 pprof 接口，避免把调试端口暴露到生产网络。

```yaml
services:
  influxdb:
    image: {{ image.amd64.reference }}
    container_name: influxdb
    restart: always
    ports:
      - "8086:8086"
    volumes:
      - /home/application/Database/influxdb/data:/var/lib/influxdb2
      - /etc/localtime:/etc/localtime:ro
    environment:
      TZ: Asia/Shanghai
      INFLUXD_PPROF_DISABLED: "true"
      DOCKER_INFLUXDB_INIT_MODE: "setup"
      DOCKER_INFLUXDB_INIT_USERNAME: "tsingyun"
      DOCKER_INFLUXDB_INIT_PASSWORD: "YOUR_INFLUXDB_PASSWORD"
      DOCKER_INFLUXDB_INIT_ORG: "tsingyun"
      DOCKER_INFLUXDB_INIT_BUCKET: "tsingyun"
      DOCKER_INFLUXDB_INIT_ADMIN_TOKEN: "YOUR_INFLUXDB_ADMIN_TOKEN"
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8086/ping"]
      interval: 30s
      retries: 3
      start_period: 30s
      timeout: 10s
    networks:
      - tsingyun

networks:
  tsingyun:
    external: true
```

## 启动容器

```bash
cd /home/application/Database/influxdb
docker-compose up -d
docker-compose ps
```

## 打开控制台

浏览器打开 `http://YOUR_SERVER_IP:8086`，使用 compose 中配置的用户名和密码登录（示例用户名为 `tsingyun`）。

管理员 Token 与密码保存在密钥系统，不要写入文档或提交到仓库。数据目录必须纳入备份。
