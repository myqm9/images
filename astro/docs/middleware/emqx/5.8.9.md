采用 docker-compose 容器编排方式部署。本页为 EMQX 5.8.9。5.8 之后不再开源，商业场景可免费使用单节点。老版本（OpenSSL 过低时才用）请用标题旁的版本切换。

:::caution
初始化用户名、密码、组织和 Token 写在 compose 的环境变量中，**生产环境必须改成自己的密钥**，不要使用文档中的占位符。
:::

## 发布信息

- AMD64 镜像：`{{ image.amd64.reference }}`
- ARM64 镜像：`{{ image.arm64.reference }}`

## 前提条件

- 已完成 [Docker 与 Compose](/prerequisites/docker/) 安装，并已创建 `tsingyun` 自定义网络。
- ARM64 主机请将下方 compose 中的 `image` 换成发布信息中的 ARM64 镜像。

## 创建工作目录

```bash
mkdir -p /home/application/Middleware/emqx/{log,data}
chmod -R 777 /home/application/Middleware/emqx/{log,data}
```

## 编写 docker-compose.yml

编辑 `/home/application/Middleware/emqx/docker-compose.yml`：

```yaml
services:
  emqx:
    image: {{ image.amd64.reference }}
    container_name: emqx
    networks:
      - tsingyun
    ports:
      - 18083:18083
      - 1883:1883
      - 18080:8081
      - 18883:8883
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - /home/application/Middleware/emqx/log:/opt/emqx/log
      - /home/application/Middleware/emqx/data:/opt/emqx/data
      - /etc/localtime:/etc/localtime:ro
    restart: always

networks:
  tsingyun:
    external: true
```

## 启动容器

```bash
cd /home/application/Middleware/emqx
docker-compose up -d
docker-compose ps
```

## 登录 Dashboard

- 地址：`http://YOUR_SERVER_IP:18083`
- 默认用户名 / 密码：`admin` / `public`

首次登录后立即修改密码。

![EMQX Dashboard 登录](/images/middleware/emqx/login.png)

登录后进入集群概览，再到「客户端认证」创建认证。

![EMQX 集群概览](/images/middleware/emqx/cluster-overview.png)

认证方式选择 **Password-Based**：

![选择 Password-Based 认证](/images/middleware/emqx/auth-method.png)

数据源选择 **内置数据库**：

![选择内置数据库作为数据源](/images/middleware/emqx/auth-datasource.png)

配置参数建议使用明文密码、用户名账号、不加盐，再点击创建：

![配置认证参数](/images/middleware/emqx/auth-params.png)

创建成功后状态应为已连接：

![认证列表已连接](/images/middleware/emqx/auth-list.png)

进入用户管理，添加业务 MQTT 用户。设为超级用户后将跳过后续权限检查，生产环境按需勾选。

![添加 MQTT 用户](/images/middleware/emqx/add-user.png)

## 使用 MQTTX 验证

从 [MQTTX 下载页](https://mqttx.app/zh/downloads) 获取客户端【见交付物清单】。连接 `YOUR_SERVER_IP:1883`，填写已创建的用户名和密码。

![MQTTX 连接配置](/images/middleware/emqx/mqttx-connect.png)

订阅并发布同一主题，确认收发成功。

![MQTTX 订阅与收发验证](/images/middleware/emqx/mqttx-pubsub.png)
