采用 docker-compose 容器编排方式部署。本页为 EMQX 4.3，老版本，仅在 OpenSSL 过低时使用。使用内置 Mnesia 认证，用 EMQX 自带数据库存储 Client ID / Username 与密码，可通过 HTTP API 管理。EMQX 5 请用标题旁的版本切换。

:::caution
初始化用户名、密码、组织和 Token 写在 compose 的环境变量中，**生产环境必须改成自己的密钥**，不要使用文档中的占位符。
:::

## 发布信息

- AMD64 镜像：`{{ image.amd64.reference }}`

4.3 仅提供 AMD64 镜像。

## 前提条件

- 已完成 [Docker 与 Compose](/prerequisites/docker/) 安装，并已创建 `tsingyun` 自定义网络。

## 创建工作目录

```bash
mkdir -p /home/application/Middleware/emqx/{log,data}
chmod -Rf 777 /home/application/Middleware/emqx/{log,data}
```

## 编写 docker-compose.yml

编辑 `/home/application/Middleware/emqx/docker-compose.yml`。Dashboard 与 MQTT 用户密码必须改成自己的密钥。

```yaml
services:
  emqx:
    image: {{ image.amd64.reference }}
    container_name: emqx
    networks:
      - tsingyun
    environment:
      - EMQX_LOADED_PLUGINS="emqx_management,emqx_auth_mnesia,emqx_auth_http,emqx_dashboard"
      - EMQX_auth__user__1__username=YOUR_MQTT_USERNAME
      - EMQX_auth__user__1__password=YOUR_MQTT_PASSWORD
      - EMQX_auth__user__password=plain
      - EMQX_DASHBOARD__DEFAULT_USER__LOGIN=YOUR_DASHBOARD_USER
      - EMQX_DASHBOARD__DEFAULT_USER__PASSWORD=YOUR_DASHBOARD_PASSWORD
      - EMQX_NODE__MAX_PORTS=65535
      - EMQX_MQTT__MAX_PACKET_SIZE=16MB
      - TZ=Asia/Shanghai
    ports:
      - 18083:18083
      - 1883:1883
      - 18080:8081
      - 18883:8883
    volumes:
      - /home/application/Middleware/emqx/log:/opt/emqx/log
      - /home/application/Middleware/emqx/data:/opt/emqx/data
      - /etc/localtime:/etc/localtime:ro
    restart: always

networks:
  tsingyun:
    external: true
```

compose 已预置 Mnesia 认证插件、明文密码和一个 MQTT 用户。

## 启动容器

```bash
cd /home/application/Middleware/emqx
docker-compose up -d
docker-compose ps
```

## 登录 Dashboard 并启用 Mnesia 认证

Dashboard 账号使用 compose 中的 `EMQX_DASHBOARD__DEFAULT_USER__LOGIN` / `PASSWORD`。

- 地址：`http://YOUR_SERVER_IP:18083`

![EMQX 4.3 Dashboard 登录](/images/middleware/emqx/v4-login.png)

登录后打开「设置」，主题选明亮，语言选中文，点击应用。

![设置明亮主题与中文](/images/middleware/emqx/v4-dashboard-theme.png)

打开「插件」，找到 `emqx_auth_mnesia`，点击启动。

![启动 emqx_auth_mnesia 插件](/images/middleware/emqx/v4-plugin-mnesia.png)

## 使用 MQTTX 验证

从 [MQTTX 下载页](https://www.emqx.com/zh/try?product=MQTTX) 获取客户端【见交付物清单】。

新建连接：协议 `mqtt://`，地址 `YOUR_SERVER_IP`，端口 `1883`，用户名和密码填写 compose 中的 MQTT 账号。

![MQTTX 连接配置](/images/middleware/emqx/v4-mqttx-connect.png)

添加订阅主题 `junkman`，再向同一主题发布消息，确认能收到。

![MQTTX 订阅与收发验证](/images/middleware/emqx/v4-mqttx-pubsub.png)
